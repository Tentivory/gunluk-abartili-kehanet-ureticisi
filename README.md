# Günlük Abartılı Kehanet Üreticisi

## Resmi Açıklama

Bu repository, insanlık tarihinin en önemli yazılım projelerinden biridir. Günlük hayatınızdaki en kritik kararları (ne yiyeceğiniz, kırmızı ışıkta ne düşüneceğiniz, çayınızın demlenme süresi) bilimsel bir şekilde çözer.

**Doğruluk oranı:** %100 (idare eder seviyesinde)

**Kullanım alanları:**
- Sabah uyanınca ne yapacağınızı bilmediğiniz anlar
- Toplantılarda "bir şeyler söylemem lazım" hissi
- Hayatın anlamını sorduğunuzda "idare eder" cevabını bilimsel olarak desteklemek

## Kurulum

```bash
git clone https://github.com/Tentivory/gunluk-abartili-kehanet-ureticisi.git
cd gunluk-abartili-kehanet-ureticisi
python3 kehanet.py
```

Başka bir şey gerekmez. Python yeter. Çünkü kehanet zaten her yerde.

## Nasıl Çalışır?

1. Program sizi selamlar (abartılı bir şekilde).
2. Adınızı sorar (çünkü kişiselleştirme önemlidir, idare eder seviyede).
3. Rastgele bir kehanet seçer.
4. Güven yüzdesi verir (0-100 arası, genellikle idare eder).
5. Damga basar.

## Örnek Çıktı

```
=== GÜNLÜK ABARTILI KEHANET ÜRETİCİSİ v1.0 ===
Adınızı girin ey kaderin piyonu: Kayyum
Kayyum, bugünün resmi kehaneti: Bugün çayınız demlenirken...
Güven seviyesi: %42 (İdare eder aralığında)
```

## Lisans

Bu proje MIT lisansı altındadır. Yani yapabilirsiniz ne isterseniz, ama kehanetlerin sorumluluğunu biz almayız. Mahkeme de almaz.

## Katkıda Bulunma

Pull request açabilirsiniz. Ama lütfen kehanetleri daha abartılı yapın. "İdare eder" kelimesini sık kullanın.

## Uyarı

Bu yazılım gerçek kehanet değildir. Gerçek kehanet için falcıya gidin veya çay yapın.
